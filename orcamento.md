# Orçamento - Sistema de Gerenciamento de Dados Itaiquara

## 1. Visão Geral do Projeto

Sistema especializado para gerenciamento de dados geográficos e contratuais da Itaiquara Alimentos SA, desenvolvido com tecnologias modernas e interface gráfica intuitiva.

### 1.1 Principais Funcionalidades

- Interface gráfica moderna e responsiva usando Flet
- Gerenciamento avançado de dados em Excel
- Sistema de histórico de alterações (criação, edição, exclusão)
- Geração automática de arquivos KML para visualização geográfica
- Sistema de busca e filtros em tempo real
- Paginação otimizada de dados
- Edição em tempo real com validações
- Controle granular de permissões por coluna

### 1.2 Tecnologias Utilizadas

- **Python**: Linguagem principal de desenvolvimento
- **Flet**: Framework moderno para interface gráfica
- **Pandas**: Manipulação eficiente de dados
- **SimpleKML**: Geração de arquivos KML
- **Logging**: Sistema robusto de logs
- **Excel**: Armazenamento e gestão de dados
