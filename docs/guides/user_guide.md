# 📖 Guia do Usuário - KML Itaiquara

## 🚀 Introdução

Este guia fornece instruções detalhadas sobre como usar o Gerador de KML Itaiquara para visualizar a distribuição territorial das unidades no Google Earth.

## 📋 Requisitos

- Google Earth Pro instalado
- Arquivo base `BRUNO.xlsx`
- Windows, macOS ou Linux

## 🎯 Funcionalidades Principais

### 1. Interface Gráfica
![Interface](../images/interface.png)

#### Elementos da Interface:
- 📂 Botão "Carregar Dados"
- 🗺️ Botão "Gerar KML"
- 📊 Barra de Progresso
- 📁 Botão "Abrir Pasta"

### 2. Fluxo de Trabalho

1. **Iniciar o Aplicativo**
   ```bash
   python src/interface.py
   ```

2. **Carregar Dados**
   - Clique em "Carregar Dados"
   - Aguarde o processamento inicial
   - Verifique a barra de progresso

3. **Gerar KML**
   - Selecione os tipos desejados
   - Clique em "Gerar KML"
   - Acompanhe o progresso

4. **Visualizar no Google Earth**
   - Abra o Google Earth Pro
   - Arraste o arquivo KML
   - Explore os dados

## 🎨 Tipos de KML

### 1. KML por Tipo de Unidade
- 🏢 Regional
- 🏪 Filial
- 📍 Em Branco

### 2. KML Unificado
- Todos os tipos em um arquivo
- Organização hierárquica
- Cores distintas por razão social

## 📊 Visualização dos Dados

### Informações Disponíveis
- Nome do município
- População
- Distribuidor
- Contatos
- Endereço

### Dicas de Visualização
1. Use as pastas para filtrar dados
2. Ajuste a opacidade se necessário
3. Ative/desative camadas conforme necessário

## ⚡ Dicas e Truques

### Performance
- Feche outros programas pesados
- Use SSD para melhor velocidade
- Processe em partes se necessário

### Organização
- Mantenha backups dos arquivos
- Use nomes descritivos
- Organize por data/região

## ❓ Solução de Problemas

### Problemas Comuns

1. **Erro ao Carregar Dados**
   - Verifique o formato do arquivo
   - Confirme as colunas necessárias
   - Tente reabrir o arquivo

2. **KML Não Abre**
   - Reinstale o Google Earth
   - Verifique o tamanho do arquivo
   - Tente gerar novamente

3. **Dados Incorretos**
   - Valide o arquivo fonte
   - Verifique a codificação
   - Confira as coordenadas
