# 📝 Changelog

Todas as mudanças notáveis neste projeto serão documentadas neste arquivo.

O formato é baseado em [Keep a Changelog](https://keepachangelog.com/pt-BR/1.0.0/),
e este projeto adere ao [Versionamento Semântico](https://semver.org/lang/pt-BR/).

## [1.0.0] - 2024-01-12

### ✨ Adicionado
- Interface gráfica moderna com Flet
- Geração de KML unificado
- Processamento otimizado de dados
- Nova paleta de cores por razão social
- Sistema de logging aprimorado
- Documentação completa
- Testes automatizados

### 🔄 Modificado
- Refatoração completa do processamento de dados
- Melhoria na organização do código
- Otimização do uso de memória
- Interface mais intuitiva

### 🐛 Corrigido
- Problemas de codificação de caracteres
- Erros na geração de cores
- Validação de dados aprimorada

## [0.9.0] - 2023-12-15

### ✨ Adicionado
- Primeira versão beta
- Suporte básico a KML
- Processamento inicial de dados
- Interface de linha de comando

### 🐛 Corrigido
- Correções na leitura de arquivos
- Ajustes no processamento de coordenadas

## [0.8.0] - 2023-11-30

### ✨ Adicionado
- Versão alpha inicial
- Estrutura básica do projeto
- Processamento básico de Excel
- Geração simples de KML
